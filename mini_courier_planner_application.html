System Design & Algorithmic Pipeline Architecture

The Mini-Courier Planner combines four core algorithmic paradigms into a sequential optimization engine. The problem requires prioritizing packages under capacity constraints and finding the optimal route for execution.

Step 1

Parcel Sorting

Sorts items by priority score, deadline, or value-to-weight density ratio.

Time: $\mathcal{O}(N \log N)$
Step 2

0/1 Knapsack DP

Selects the optimal subset of packages fitting maximum truck capacity $W$.

Time: $\mathcal{O}(N \cdot W)$
Step 3

Dijkstra's Algorithm

Calculates shortest point-to-point paths between delivery hubs.

Time: $\mathcal{O}((V+E)\log V)$
Step 4

TSP Nearest-Neighbor

Approximates the full round-trip route sequence covering selected destinations.

Time: $\mathcal{O}(V^2)$

Formal Problem Formulation

1. Vehicle Loading (0/1 Knapsack)

Maximize total selected value subject to weight limit $W$:

$$\max \sum_{i=1}^{N} v_i x_i \quad \text{subject to} \quad \sum_{i=1}^{N} w_i x_i \le W, \quad x_i \in \{0, 1\}$$

2. Route Optimization (TSP)

Minimize total travel distance across selected nodes $V_s \subseteq V$:

$$\min \sum_{k=1}^{|V_s|-1} d(v_{\pi(k)}, v_{\pi(k+1)}) + d(v_{\pi(|V_s|)}, v_{\text{depot}})$$

Final Capstone Technical Report

Summary of algorithmic tradeoffs, repository structure, and execution steps.

Sorting Tradeoffs

QuickSort/MergeSort provide $\mathcal{O}(N \log N)$ sorting efficiency. Pre-sorting parcels by value-to-weight ratio allows rapid greedy estimations prior to DP optimization.

Knapsack DP Optimization

0/1 Dynamic Programming guarantees exact global optimality for discrete cargo constraints within pseudo-polynomial time $\mathcal{O}(N \cdot W)$.

Graph Routing Scalability

Dijkstra with priority queues computes single-source paths efficiently. Nearest-Neighbor TSP guarantees quick $\mathcal{O}(V^2)$ tours for real-time dispatch.
